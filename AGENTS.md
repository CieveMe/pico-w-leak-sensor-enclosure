# Project guidance

This is a public, reproducible mechanical learning prototype. Use only public component specifications; never import the parent workspace's personal records, client files, credentials or chat logs.

Keep CAD source and dimensional assumptions traceable. Derived files must come from the same source revision. Do not claim physical testing, waterproof certification or community adoption without evidence. The browser viewer is illustrative; geometry validation uses assembled CAD coordinates.

Read docs/design.md. Keep validation meaningful: check real geometry, export/reimport and parameter changes. Prefer isolated project dependencies. Do not overwrite unrelated files or commit local environments.
